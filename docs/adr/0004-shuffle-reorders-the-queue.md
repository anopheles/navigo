# Shuffle reorders the queue; there is no shuffle mode

`shuffle` is a one-shot command that reorders the queue at random and can be undone like any other queue edit. There is no hidden play order. What the queue window shows is always what plays next, which keeps navigo easy to learn and fits the queue-as-vim-buffer model. Repeat stays a mode (off / all / one), shown in the now-playing bar.
