# The radio tops up the queue ahead, and steering lasts only for the session

The radio keeps playback going after the queue's last track. It does so by adding tracks to the queue before it runs out: when a track starts within the last 3 rows, 10 tracks are picked and appended, marked as the radio's. We chose topping up ahead over picking one track as the last one ends because the listener then sees what is coming and can remove or reorder it with the queue's usual keys, and because a pick that waits on the server's similar artists (up to 2 s) never leaves a silence between tracks. The pick is the Mix around a seed of [ADR 0007](0007-a-mix-around-a-seed-asks-the-server-for-similar-artists.md), with the last 5 tracks played as the seed: one track would let a single song derail it, and whatever started the session would never drift. The radio's additions are not undo steps, so `u` keeps undoing the listener's own edits; the queue is still owned by navigo as [ADR 0002](0002-navigo-owns-the-queue.md) says, and the core decides when to top up while the UI supplies the time and the random seed, as [ADR 0001](0001-single-writer-core-with-effects-as-data.md) requires.

Steering is the one exception to the Mix's fixed weights. "More like this" doubles the chance of a track's artists and keeps the track in the seed; "less like this" leaves its artists out entirely and drops their upcoming radio tracks. Less was first a tenth of the weight, but on a library where few tracks are close the radio brought the same artist straight back, which reads as the key not working. Both last only for the session. Saving them would turn a moment's mood into a lasting setting the listener can't see, and the Mix would quietly differ from its documented weights; we would rather keep one set of weights in the spec and let the radio be steered while it plays.

We rejected making the radio a fourth state of repeat (off, all, one, radio). Repeat all and the radio do exclude each other, since the queue never runs out under repeat all, and turning one on turns the other off; but a four-way cycle on `R` hides the radio and makes repeat slower to set. We also rejected having it always on: a listener who plays an album expects silence after its last track.
